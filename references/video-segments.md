# 演示、配音与异常片段

有信息的演示配音默认保留，并与现场解说区分。交付需要独立片段时再裁视频。

## 定位候选

有本地媒体且音轨可用时，可运行：

```bash
python3 <SKILL_DIR>/scripts/scan_segments.py <视频> --segments <转写目录>/segments.json --out <输出目录>/音轨扫描.json
```

没有时间分段文件时省略 `--segments`，不能伪造对应关系。该文件需与视频使用同一时间基准。

扫描按能量和停顿找出候选，不识别人声身份，不证明哪段是演示。字幕空白也可能是漏听；连续能量下既可能有配乐，也可能有配乐上的真实人声。回听候选并结合画面、文字确认后再判断，不能直接删掉「可疑」文本。无法回听时将结论标为未验证。

保留原转写，修订另存，记录删除的范围和理由。发现疑似漏转写时重查该段而不是补写。

## 文本与裁片

有用配音：在对应正文写「演示配音：……」。来源不清楚则标明；纯音乐可写「播放演示，无可辨认语音」，前提是已检查。不要用一行「播放视频」代替独有知识或操作步骤。

裁片先判断用户需要整屏还是页面区域；已有明确上下文就按它执行，否则默认保留完整画面以免丢掉操作和讲者信息，在交付时说明范围。裁剪到 PPT 区域时先验证该段布局稳定。

```bash
ffmpeg -i "input.mp4" -ss <开始秒> -t <持续秒> -c:v libx264 -crf 20 -c:a aac -movflags +faststart "segment.mp4"
```

这是重编码示例，使用未占用的输出路径。长视频可优化定位方式，但必须核对实际首尾帧、声音及时间，不能仅凭参数认定精准。粗扫描定位后在边界附近加密查看；动画内部变化不自动视为片段结束。

保留来源、原视频时间、裁剪范围和片段路径。批量输出使用唯一编号，避免同名前缀互相覆盖。链接相对于最终文档，移动交付目录后仍应有效。
