# 本地转写

**有可靠字幕或速记时先复用**；确实需要听写才用此路线。

只处理**本地媒体**：不上传音频、不调用商业 API、不需要 API key、**不自动下载模型**。
运行时与模型路径由参数或环境变量提供，**脚本里不写死任何机器的路径**。

先读 [`prerequisites.md`](prerequisites.md)。

---

## 入口

```bash
python3 <SKILL_DIR>/scripts/local_asr.py doctor --model <模型文件>
python3 <SKILL_DIR>/scripts/local_asr.py transcribe <媒体> --out <新输出目录> \
        --model <模型文件> --language auto --duration 15
```

`--ffmpeg` / `--ffprobe` / `--whisper-cli` / `--model` 是**子命令的参数**，
写在子命令**之后**。也可用环境变量 `LOCAL_ASR_FFMPEG`、`LOCAL_ASR_FFPROBE`、
`LOCAL_ASR_WHISPER_CLI`、`LOCAL_ASR_MODEL`。路径含空格或中文时按参数数组传。

**先用有人声的短段跑一遍**（`--duration 15`），确认模型能加载、文字可用；
全段另用**新目录**并去掉 `--duration`。

> `doctor` 只是**环境检查**，不等于听写成功。

### 可选开关

| 开关 | 用途 |
|------|------|
| `--no-gpu` | 显式走 CPU。GPU 后端起不来时用（例如运行时分配不了 buffer）——**不会静默降级** |
| `--chunk-seconds N` | 把长音频拆成可独立续跑的块。**为「续跑」而拆，不是为「能跑」而拆** |
| `--resume` | 复用已完成的 `raw/chunk-*.json`。**只在输入、模型和影响转写的设置一致时复用**——不能复用另一段视频的同名文件 |
| `--start` / `--duration` | 只处理一段（小样）。时间戳仍映射回**原视频绝对秒数** |

> **音视频分离时**（一条无声画面 + 一条纯音频）：转写传**声音**那条。
> 传错文件会明确报「没有音轨」，不会静默跑出一堆空结果。

## 产物

| 文件 | 说明 |
|------|------|
| `原文.md` | **纯正文**，后续整理与 diff 的基准。时间戳、元数据、诊断信息**不得混入** |
| `带时间戳.md` | 同样正文，每段前置 `[起–止]`，给人看、供回听定位 |
| `segments.json` | 分段结构：`id` / `start` / `end` / `text` / `source_span` / `chunk_id` |
| `asr-quality.json` | 引擎是否跑完 + 结构是否合法 |
| `manifest.json` | 源媒体与模型的 SHA-256、完整运行参数 |
| `raw/chunk-*.json` | whisper.cpp 原生 JSON，保留供追溯 |

- 时间轴是**原视频绝对秒数**（`timebase: source_media_seconds`）
- `source_span` 是该段文本在 `原文.md` 中的 **Unicode code point 左闭右开范围**
- `id` **全局唯一**；没有可靠词时间戳时 `words` 保持 `null`
- whisper.cpp 原生 JSON 里 `offsets` 是**毫秒**，`timestamps` 是 `HH:MM:SS,mmm` 字符串——
  脚本已按此换算，改动解析时注意别把两者混了

## 质量边界

`asr-quality.json` 的 `completed` 只表示**引擎跑完且产物结构合法**，**不表示人工质检通过**。
中文专名、数字、跨块边界、静音 / 音乐段和片尾都需要抽样回听。

**ASR 质量、PPT 页数、整理 diff 是三件事，分开报告，不要互相背书。**

### 分块要额外注意两点

- **块边界可能出现幻觉。** 整块落在静音 / 纯音乐上时，whisper 会输出与内容无关的文本
  （典型如「请不吝点赞 订阅 转发」这类字幕模板）。**全量单块跑同一区间通常不会。**
  拆块后**必须抽查块边界**；不确定就**退回不拆块重跑**。
- **块边界由 `-ss` 快速定位**，可能与标称时间有**亚秒级偏差**，跨块处的时间戳需回听核对。

### 回查

专名、数字、静音 / 配乐、块边界。

- **不能看到一段常见字幕套话就自动删除**——那也可能是真的
- **没有可用回听工具时，明示检查范围**（说清哪些质量检查没做）
- **保留原转写、修订另存**
- 不要把**缺少语言信息**或**没有音轨**当成模型识别完成
