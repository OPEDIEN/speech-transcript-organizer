# 材料与依赖前置检查

先盘点材料，再检查所选路线需要的能力。检查脚本只读取运行条件和测试输入，依赖安装与材料获取按实际缺项处理。

## 先核对材料是否属于同一段内容

检查视频时长、字幕覆盖范围、语言和版本，抽看开头/中间/结尾的对应关系。全场字幕可能搭配截断视频，不能把媒体范围之外的字幕塞进最后一页；仅使用能对应当前视频的范围，边界跨句时核对词时间或回听。保留原字幕，裁选结果另存并记录范围。原 PPT 页数也不等于视频实际讲到的次数。

## 按需检查表

| 要做什么 | 必需条件 | 验证方式 |
|---|---|---|
| 文字整理与差异报告 | 能理解材料的 AI 环境；Python 3.10+；可读文字和可写输出目录 | Python 实际运行；输入编码/正文结构可读；输出目录创建临时文件后删除 |
| 视频抽页、扫描、裁片 | ffmpeg、ffprobe；可解码视频/音轨 | 读取媒体信息并解码短视频/音频样本 |
| 本地听写 | 上述媒体工具；whisper-cli；兼容模型文件 | 先检查路径、命令退出状态；再用真实短音频加载模型并听写，成功后才跑全段 |
| 在线材料获取 | 当前网站可用的授权下载/浏览器能力 | 先验证链接和访问，按需检查下载工具 |
| PPT/PDF 变图片 | 当前环境支持该格式的渲染工具 | 先转换一页并检查图片清晰度 |
| 看图与回听 | 当前 AI 工具实际支持图片/音频检查 | 用小样验证；不支持时说明哪些质量检查未完成 |

提供标准库检查脚本：

```bash
python3 <SKILL_DIR>/scripts/preflight.py --out-dir <输出目录>
python3 <SKILL_DIR>/scripts/preflight.py --media <视频> --video --out-dir <输出目录>
python3 <SKILL_DIR>/scripts/preflight.py --media <视频> --asr --model <模型文件> --out-dir <输出目录>
```

脚本检查 Python、目录、命令实际启动、媒体信息和短样本解码；`--asr` 还检查模型可读且非空。需要听写时，再用 `local_asr.py transcribe ... --duration 15` 确认模型能实际加载并生成文字。静音开头应换有人说话的片段。

参数可显式给工具路径；模型也可通过 `LOCAL_ASR_MODEL` 提供。检查可用磁盘空间是否足够容纳音频、抽帧和模型；脚本报告剩余空间，但容量是否足够仍取决于本次计划。工具路径由当前环境确定，记录实际使用的 Python 和工具位置。报告列出通过项、影响当前路线的缺项和下一步。

## 缺依赖怎么办

先查当前环境已有工具和等价能力。需要安装或下载时说明名称、用途、来源与体积；遵循已有授权和系统权限，不重复索取已给的批准。没有授权时不要静默下载大型模型，也不要擅自改用收费服务或上传用户视频。继续不依赖该工具的工作。

转写安装参考官方 whisper.cpp 项目：<https://github.com/ggml-org/whisper.cpp>。模型使用其官方说明指向的来源；下载前确认平台、模型语言、存储和内存条件。若来源提供可信校验值，下载后比对；仅自行计算哈希只能用于后续识别文件，不能宣称已验证来源。

按当前操作系统选择工具。命令启动失败时查明错误，再修复或选择等价工具；GPU 失败时可明确改用 CPU。
